I build with security in mind from day one:

- Protection against **SQL Injection** (parameterized queries, ORM and input validation)
- **REST APIs** with authentication, authorization and data validation
- **Linux** server hardening and infrastructure best practices
- Environment isolation with **Docker** and access control on **AWS**
